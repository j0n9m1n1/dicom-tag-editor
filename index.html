자주 묻는 질문 (FAQ)

DICOM 파일이나 환자 정보가 외부 서버로 전송되나요?

아니요. 모든 파싱·편집·익명화·저장 작업은 브라우저 로컬 메모리에서만 실행되며 어떤 데이터도 외부 서버로 전송되지 않습니다. PWA로 설치하면 오프라인 상태에서도 그대로 동작합니다.

태그를 수정하고 저장하면 PixelData 영상 데이터가 손상되거나 재압축되나요?

아니요. 수정하지 않은 PixelData 바이트는 비압축 8/16비트 영상은 물론 JPEG, JPEG 2000, JPEG-LS, RLE 등 압축 스트림까지 원본 바이트 그대로 무손실 유지되며, 편집한 태그와 File Meta 길이만 정확히 갱신됩니다.

두 개의 DICOM 파일 태그를 나란히 비교할 수 있나요?

네. 두 개 이상의 .dcm 파일을 연 뒤 상단 툴바의 비교(Compare)를 누르면 File Meta와 Main Dataset 순서대로 차이점·A 전용·B 전용 태그를 좌/우 분할 화면에서 비교할 수 있습니다.

어떤 DICOM Transfer Syntax와 표준 태그(MPPS 등)를 지원하나요?

Explicit VR Little/Big Endian, Implicit VR Little Endian, Deflated Explicit VR 및 Part 10 DICM 헤더가 없는 Raw DICOM까지 읽을 수 있으며, MPPS·MWL을 포함한 5,041개 이상의 표준 PS3.6 태그를 인식합니다.

데스크톱 앱처럼 설치해 탐색기에서 .dcm 파일을 바로 열 수 있나요?

네. Chrome·Edge에서 앱 설치(PWA)를 완료하면 오프라인 단독 창으로 실행할 수 있으며, OS .dcm/.dicom 파일 연결을 통해 탐색기에서 바로 열어 Ctrl+S로 덮어쓰기 저장할 수 있습니다.
